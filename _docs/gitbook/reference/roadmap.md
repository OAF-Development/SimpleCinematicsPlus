# Roadmap

Planned work, roughly in order. None of it is promised, and plans change with testing.

| Feature | Status |
| --- | --- |
| [Waypoint paths](../features/waypoint-paths.md) (placing, coloured ribbons and path events built; in testing) | In development |
| Editable walk duration and direction | Planned |
| "Keys relative to target" mode, so camera keys ride along with a moving actor | Planned |
| Bullet material polish (metallic copper, brass or steel by calibre, optional tracer glow) | Planned |
| Death animations without dying, through a custom emote slot and Pose Hold | Exploring |
| Placeable, switchable actors, each with its own timeline track | Exploring |
| Navmesh pathfinding and recorded takes | Later |

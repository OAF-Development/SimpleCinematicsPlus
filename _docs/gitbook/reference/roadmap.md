# Roadmap

Planned work, roughly in order. None of it is promised, and plans change with testing.

| Feature | Status |
| --- | --- |
| [Waypoint paths](../features/waypoint-paths.md) (placing, dragging, rounded corners, coloured strips and path events built) | In testing |
| Editable walk duration | Done: drag the end of the event bar |
| Walk direction | Replaced by waypoint paths and the actor track |
| Camera moving with a walking actor | Done: [Follow Actor and Auto-Key](../features/auto-key.md) |
| Recording an actor's movement | Done: [actor track](../features/auto-key.md#actor-track) |
| Bullet material polish (metallic copper, brass or steel by calibre, optional tracer glow) | Planned |
| Death animations without dying, through a custom emote slot and Pose Hold | Exploring |
| Placeable, switchable actors, each with its own timeline track | Exploring |
| Navmesh pathfinding | Later |

See [What's new](changelog.md) for what has changed so far.
